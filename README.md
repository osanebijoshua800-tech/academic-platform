# academic-platform
Full-stack educational SaaS MVP designed for seamless student-tutor engagement. Includes real-time classroom chat rooms, responsive Tailwind UI with theme switching, and secure REST APIs.

# 🎓 Academic Platform MVP

An end-to-end, real-time academic platform designed to bridge distance learning and interactive mentorship.

## 🚀 Key Features
- 💬 **Real-Time Classroom Chat**: Socket.IO-powered messaging rooms per course module.
- 📂 **Assignment Management**: Submit solution files and receive instant feedback.
- 🎓 **Verifiable Certificates**: Download high-resolution PDF completion certificates directly from the dashboard.
- 🌙 **Light & Dark Theme**: Built-in theme switcher with `localStorage` persistence and glassmorphism UI.
- 🔐 **Role-Based Auth**: Tailored interfaces and permissions for Students and Tutors.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+), WebSockets
- **Backend**: Node.js, Express.js
- **Real-Time Engine**: Socket.IO
- **Database**: SQLite
